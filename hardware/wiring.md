# Kindle Touch 硬件改造文档

## 设备信息

- **型号**: Kindle Touch (第7代触屏版)
- **屏幕**: 6寸 E Ink Pearl，分辨率 600x800
- **处理器**: Freescale i.MX508 @ 800MHz
- **内存**: 256MB RAM
- **存储**: 4GB NAND Flash
- **电池**: 内置 3.7V 锂电池 (约 1000mAh)
- **接口**: Micro USB (充电/数据)

## 改造目标

将 Kindle Touch 改造成插电式桌面台历，移除电池以简化设计。

## 硬件改造步骤

### 准备工具

- T5 梅花螺丝刀
- 撬棒/塑料卡片
- USB-C 电源线 (5V 1A)
- 电烙铁 (可选，用于加固)
- 万用表 (测试用)

### 拆机步骤

1. **移除后盖**
   - 关闭电源
   - 用 T5 螺丝刀拧下背部 6 颗螺丝 (底部2颗在橡胶塞下方)
   - 用撬棒轻轻撬开后盖，从底部开始

2. **断开电池** (可选)
   - 找到电池接口 (橙色排线)
   - 轻轻抬起锁扣，断开电池连接
   - 如完全移除电池，请小心处理

3. **找到 USB 电源接口**
   - 主板位于设备中央
   - Micro USB 端口在主板边缘

### 改装方案

#### 方案 A: USB-C 直连供电 (推荐)

```
材料:
- USB-C 转 Micro USB 转接头 或
- USB-C 电源线 + 手工焊接线
- 5V 2A USB 电源适配器

步骤:
1. 找到主板上的 USB 数据线 (GND, VBUS, D+, D-)
2. 将 USB-C 的 5V 和 GND 连接到主板 USB 焊点
3. 建议添加一个 1000µF 电容滤波 (可选)
```

#### 方案 B: 直接焊接 5V 供电线

```
材料:
- 漆包线 (AWG 26-28)
- 5V 2A 电源模块

步骤:
1. 找到主板上 5V 电源测试点或电容
2. 焊接 +5V 和 GND 线
3. 绝缘处理焊点
4. 引出到外壳侧面 USB-C 端口
```

### 物理按键改造

保留以下按键:
- **电源键**: 开关机
- **音量键**: 上下翻页/导航

如需添加外部按钮:
- 在外壳侧面开孔
- 连接到主板对应测试点

### 外壳处理

1. **底部开孔** (如需 USB-C 接口)
   - 在设备底部外壳用小刀开一个 USB-C 槽口
   - 用锉刀修整边缘

2. **散热考虑**
   - Kindle Touch 设计为被动散热
   - 长时间运行确保通风良好
   - 避免阳光直射

## 电源要求

- **输入电压**: 5V DC
- **输入电流**: 1A-2A
- **功率**: ~5W (最大)

**推荐电源**:
- 手机充电头 (5V 1A 或更高)
- 树莓派 USB 输出
- 电脑 USB 接口 (可能供电不足)

## 安全注意事项

1. **不要**在设备潮湿时操作
2. **不要**使用高于 5V 的电源
3. **小心**拆卸排线，不要用力拉扯
4. **注意**烙铁温度，避免烫坏塑料部件
5. **建议**保留原电池连接，以便意外断电时保护数据

## 测试步骤

1. 焊接完成后，用万用表检查短路
2. 连接 5V 电源测试
3. 观察设备是否正常启动
4. 如有问题，立即断开电源检查

## 常见问题

Q: 设备无法开机?
A: 检查 5V 电源是否稳定，焊接点是否接触不良

Q: 设备自动重启?
A: 可能是供电不足，尝试更大功率的电源适配器

Q: 屏幕闪烁?
A: 检查排线连接，或电源纹波过大，可添加滤波电容
